## Baseline and compatibility findings

- Query-v5 fixture hash matches its manifest. The parser is dirty, so the retained v5-final predictions are a historical reference rather than a verified result for today's source.
- Retrieval-v3 judgement and v4 expected-report hashes match the historical confirmation manifest. Current bundled USDA bytes do not match that manifest. This is a baseline compatibility finding, not a failed relevance score.
- Grounding's page/citation judgements, matcher decisions and OCR strict cells use different units of analysis. Preserve their original metrics alongside explicitly mapped common metrics; do not rename historical metrics to imply equivalence.
- Extraction-v3's evidence envelope is application-owned. The harness must preserve raw model extraction separately from enriched bound output.
- Correction-time records, partial live pilot summaries and synthetic state tests cannot supply OUT07 device-usability evidence.
- Extraction and hybrid assets are untracked; the audit snapshot is local provenance, not a committed baseline. Do not absorb them or unrelated source edits into an evaluation change without deliberate scope selection.

## Coverage gaps and implementation checklist

1. Define the neutral observation schema and case roster, including unavailable/error states and stage attribution. Contract-test missing/duplicate output and absent reference handling.
2. Adapt query-v5 without changing exposed labels or production parsing. Surface fictional brand-vocabulary differences.
3. Adapt development-only extraction-v3 after verifying retained document hashes and auditing reference access; preserve existing scorer results before adding common field precision/recall.
4. Add an explicitly synthetic unsupported volume-to-mass scenario. Execute the actual application validation path and export raw, blocked and saved/not-saved observations. Do not manufacture a safeguard result in a Python mock.
5. Produce the first local HTML/JSON report with AI, safeguard and outcome sections, missing suites, failure reasons, input/code/reference hashes and baseline comparability.
6. Add ranked retrieval as a distinct historical replay/current execution pair; do not promote broad labels into exact identity judgements.
7. Extend list NLP, spelling and journey/save/projection evaluation with independently authored references; keep existing contract tests in the safety profile.
8. Design independent acceptance populations, family coverage, semantic-judge validation and thresholds. Raw AI robustness/repetition, live cost/latency and physical speech/user effort remain unmeasured by this audit.
