# Local food query parser architecture and evaluation v1

Scope: offline en-GB parser, retrieval terms and quantity review. Gemini and new data sources deferred. No provider calls, automatic acceptance or saves. Parsing lives in FoodLedgerApplication, depending only on Foundation/plain values. Infrastructure adapters consume retrievalText; presentation displays variant uncertainty and clarification. Original text is retained in capture evidence. Existing immutable identity/nutrition/persistence contracts are unchanged. Retrieval policy versions increment to v5; composite policy to v3.

Stable rules: numeric quantity must be positive and finite; kg/l scale only within mass/volume, never across them. Counts require existing confirmed conversion. Multiple/conflicting amounts, vague portions, recipes and narrative context do not prefill. Numeric percentages are attributes, not injected nutrition. Only resolved exact gram fat on a per-100g basis can support an exact numeric ranking hint; unknown, bounded and other bases do not. Matching the number never establishes product identity. Brand recognition uses an explicit vocabulary; unknown words stay in retrieval text rather than being guessed away. Pure contract tests protect these rules; both existing adapters share parsed terms and provenance checks.

The 262 fixtures are exposed, correlated development material. Clarification keeps tentative food/attribute spans; strict whole-record scores include these disagreements, even when routing and quantity are correct. Report each field and ready-to-search cases separately. Expectations revised with an explicit log; no claim of performance gain against unchanged gold labels. Original personal diary is not included. A separately authored acceptance set is still required before release; no current case is an untouched holdout. Device quantity review and usability remain separate from simulator/package compilation.

Known scope limits: no general sentence decomposition, recipe inference, brand entity model, numerical interpretation of qualitative fat labels, density inference or household-serving assumptions. These inputs retain original text and require explicit review/clarification. Source coverage is distinct from parse success.
